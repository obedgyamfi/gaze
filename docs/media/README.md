# Media for the README

Drop screenshots and GIFs here, then **uncomment** the matching `<img>` line in the
root `README.md` (each placeholder is marked with `📸`). Suggested files:

| File | Where it's used | Suggested content |
|------|-----------------|-------------------|
| `demo.gif` | Top of README | ~10–20s screen capture of a full loop: launch scoped browser → traffic captured → attack-surface graph fills in → open a finding |
| `graph.png` | Graph feature | The attack-surface / security-property graph with a node selected |
| `proxy.png` | Proxy feature | The proxy log with a request selected + the request/response panes |
| `repeater.png` | Repeater feature | An edited request and its response |
| `findings.png` | Findings feature | A finding with its detail / evidence |
| `architecture.png` | Architecture (optional) | A simple diagram of scope → capture/collect → graph → oracles → findings |

Tips: keep GIFs under ~10 MB (GitHub is happier), and PNGs around 1400px wide is plenty.
